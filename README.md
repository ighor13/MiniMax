# Minimax Visualizer (Qt 6)

Кроссплатформенное приложение для наглядной визуализации алгоритма **Minimax с Alpha-Beta отсечением**. 
Проект демонстрирует, как алгоритм обходит дерево игры, как происходит оценка узлов и как работают отсечения (pruning).

## 🚀 Возможности

*   **Визуализация дерева**: Построение дерева игры фиксированной структуры (1 → 3 → 7 → 15 → 36).
*   **Анимация обхода**: Пошаговое превращение нерассчитанных узлов (кругов) в вычисленные (квадраты с числами).
*   **Alpha-Beta отсечение**: Наглядное перечёркивание ветвей, которые не влияют на итоговый результат.
*   **Условия отсечения**: Отображение сравнений (например, `3 <= 4`) под отсечёнными узлами.
*   **Гибкое управление**:
    *   Переключение корня дерева (**MAX** / **MIN**).
    *   Опция перечёркивания листьев (включить/выключить).
    *   Опция отображения условий отсечения (включить/выключить).
*   **Управление анимацией**: Кнопки **Старт**, **Пауза**, **Стоп** и **Шаг** (для ручного прохода по алгоритму).
*   **Кроссплатформенность**: Работает на **Windows** и **Android**.

## 🛠️ Требования

*   **Qt 6.12** (или новее)
*   **CMake 3.16+**
*   Компилятор:

## 📦 Сборка и запуск

### Windows (Desktop)

1.  Откройте проект в **Qt Creator**.
2.  Выберите Kit: `Desktop Qt 6.x.x MSVC2022 64bit` (или MinGW).
3.  Нажмите **Собрать** (Build) → **Запустить** (Run).

**Автоматический деплой**:
В `CMakeLists.txt` настроен вызов `windeployqt`. После сборки в папке `build/.../deploy/` появится готовая к запуску программа со всеми DLL и плагинами. 

*Примечание:* Флаг (`--release` или `--debug`) для `windeployqt` подставляется автоматически в зависимости от текущей конфигурации сборки (Debug/Release). Это гарантирует, что в папке `deploy` будут лежать правильные версии библиотек.

### Android

1.  В Qt Creator выберите Android Kit (например, `Qt 6.x.x for Android x86_64`).
2.  Убедитесь, что в настройках проекта указан правильный **AndroidManifest.xml** (в папке `android/`).
3.  Нажмите **Собрать** (Build) → **Запустить** (Run) на эмуляторе или устройстве.

**Примечание**: В `AndroidManifest.xml` установлена альбомная ориентация экрана (`android:screenOrientation="landscape"`).

## 📂 Структура проекта

*   `CMakeLists.txt` — Конфигурация сборки.
*   `main.cpp` — Точка входа.
*   `mainwindow.h/cpp` — Главное окно, логика UI и анимации.
*   `nodeitem.h/cpp` — Графический элемент узла (квадрат/круг/крест).

*   `android/` — Ресурсы Android (манифест, иконки).

## 🧠 Как это работает

1.  **Дерево**: Строится фиксированное дерево с 36 листьями. Значения листьев заданы в массиве `LEAF_VALUES` (в `gameutils.h`).
2.  **Расчёт**: Функция `minimax()` рекурсивно обходит дерево, обновляя `alpha` и `beta`. 
3.  **Отсечение**: Если `beta <= alpha`, алгоритм прекращает обход ветви и вызывает `markSubtreeAsPruned()`, которая добавляет в очередь анимации шаги для перечёркивания отсечённых узлов.
4.  **Анимация**: `QTimer` с интервалом 30 мс вызывает `stepAnimation()`, которая пошагово обновляет `NodeItem` (превращает круги в квадраты, перечёркивает отсечённые узлы, выводит условия отсечения).
